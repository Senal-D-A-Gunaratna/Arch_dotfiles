# matugen.nvim

A Material You colorscheme for Neovim that dynamically loads colors from `matugen`.

## Features
- Dynamic color loading from `matugen` JSON output.
- Support for multiple plugins (Blink, Bufferline, Gitsigns, LSP, Lualine, etc.).
- Auto-reloading on `SIGUSR1` signal (great for scripts that update your wallpaper and colors).
- Standard Neovim colorscheme integration.

## Installation

### [lazy.nvim](https://github.com/folke/lazy.nvim)

```lua
{
  "matugen.nvim", -- Or the path to your local repo
  dir = vim.fn.stdpath("config") .. "/matugen.nvim", -- If local
  lazy = false,
  priority = 1000,
  opts = {
    -- Path to the JSON file generated by matugen
    -- Default: ~/.cache/matugen/colors.json
    json_path = vim.fn.expand("~/.cache/matugen/colors.jsonc"),
  },
  config = function(_, opts)
    require("matugen").setup(opts)
    vim.cmd.colorscheme("matugen")
  end,
}
```

## Usage

Set the colorscheme:
```vim
colorscheme matugen
```

Reload the theme manually:
```vim
:MatugenReload
```

## Signal Support
The plugin listens for `SIGUSR1`. You can trigger a reload from your terminal or script:
```bash
pkill -SIGUSR1 nvim
```
